05. DESKTOP
━━━━━━━━━━━━━━━━━━━━

En desktop utilizar una composición amplia.

Las pantallas deben aparecer grandes y con suficiente separación entre ellas.

Preferentemente utilizar:

3–4 pantallas visibles simultáneamente

y permitir que el resto continúe en una segunda fila o mediante un flujo visual posterior.

Las pantallas deben mantener su proporción original.

No deformarlas.

No recortarlas de manera que se pierda información importante.

No reducirlas excesivamente.
