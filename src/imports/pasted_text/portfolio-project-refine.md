PROJECT STRUCTURE

Each project should contain:

1. Large project number
2. Large project title
3. Category / discipline tags
4. Short project description
5. Large visual area for project imagery or mockups
6. VIEW CASE STUDY → CTA
7. Small supporting metadata

The visual area should be the dominant element of each project.

The project image/mockup area should occupy approximately 60–70% of the visual attention of each project block.

PROJECT LAYOUT

Use large editorial compositions.

Do not make all four projects identical.

Alternate compositions while maintaining consistency.

Project 01:
Large visual on the left, project information on the right.

Project 02:
Project information on the left, large visual on the right.

Project 03:
Large full-width visual with project information underneath.

Project 04:
