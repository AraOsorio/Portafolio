REESTRUCTURAR LA JERARQUÍA VISUAL DE TODOS LOS CASE STUDIES SEGÚN EL MODELO DE REFERENCIA

Quiero que TODOS los Case Studies del portfolio utilicen EXACTAMENTE la misma jerarquía visual y composición editorial que la referencia visual que estoy proporcionando.

IMPORTANTE:

No quiero una reinterpretación.

No quiero una aproximación.

No quiero simplemente aumentar tamaños de texto.

Quiero replicar el SISTEMA DE JERARQUÍA, COMPOSICIÓN, PROPORCIONES Y DISTRIBUCIÓN de la referencia.

La referencia establece el lenguaje visual definitivo para los Case Studies.

Aplicar este sistema a:

MIRA APP
ONCOBOT
PROJECT BUILDER

Cada proyecto mantiene su propio contenido, imágenes, investigación y Design System, pero la estructura visual del Case Study debe seguir este mismo sistema.
